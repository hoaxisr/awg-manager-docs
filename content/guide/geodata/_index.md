Вкладка управляет файлами geosite (списки доменов) и geoip (списки подсетей) в формате `.dat`. Теги из них используют [Sing-box Router](../singbox/router/): в правилах со списками и в обходе по geoip.

![Вкладка Гео-данные](/img/guide/geodata/tab.png)

## Добавление

- **Пресеты Ground-Zerro** — готовые `geoip_GA.dat` и `geosite_GA.dat`.
- **Добавить по URL** — выберите тип и вставьте ссылку на файл. Тип должен соответствовать содержимому: файл без записей отклоняется.

## Обновление

- **Автообновление гео-файлов** — единое расписание для всех файлов: каждые N часов (рекомендуется 6–24) или ежедневно в заданное время по часам роутера.
- **Обновить все** и **Запустить обновление сейчас** перекачивают все файлы разом, **Обновить** в строке — один файл.
- В строке видно время последнего обновления, а кнопка «Источник» открывает URL, с которого файл скачан, с возможностью копирования.

## Файлы других программ

Файл с бейджем **External** принадлежит другой программе: awg-manager его только читает. **Обновить** для него недоступно, а **Удалить** убирает его из списка и оставляет на диске. Вернуть такой файл в список нельзя.
